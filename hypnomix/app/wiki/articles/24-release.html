You have a finished master. Before it goes to a distributor you still have to make the 16-bit copy, the MP3 and AAC versions, put the title, artist and cover into them, check the cover is the right shape, and make sure nothing clips once it is lossy. release does all of that, in a new folder, and tells you in plain words what it found. It never changes your master.

1 · Look first: --check

$ hypnomix release "Song master.wav" --title "Song Title" --artist "Artist Name" \
      --album "Album Name" --track 3 --year 2026 --genre Rock --isrc US-RC1-76-07839 \
      --art cover.jpg --check

Read-only. It runs the release checks on the master (the same as qc), checks the cover (square, at least 3000 px, JPEG or PNG), checks the ISRC is shaped like one (2 letters, 3 letters or digits, 2 digits, 5 digits), and prints exactly which files it would write. It exits 1 when something would stop the release, so a script can use it. Nothing is written, not even the folder.

2 · Then write the folder

$ hypnomix release "Song master.wav" --title "Song Title" --artist "Artist Name" \
      --album "Album Name" --track 3 --year 2026 --genre Rock --isrc US-RC1-76-07839 --art cover.jpg
$ hypnomix release "Song master.wav" --meta release.json --formats wav24,wav16,mp3,aac,flac --out ~/Releases

It makes a new folder Artist Name - Song Title/ (and refuses if that folder exists):

  • 24-bit WAV: your master, byte for byte when it is already a 24-bit WAV. Never re-processed.
  • 16-bit WAV: made from the unrounded master with the same dither master uses (resampled to 44.1 kHz first if the master is not), so the rounding happens once. --dither tpdf|shaped|off picks it.
  • MP3 320 and AAC 256 (.m4a) with title, artist, album, track, year, genre and the cover embedded; the MP3 and the optional FLAC also carry the ISRC (AAC has no standard place for it, so it is in release.json).
  • cover (a copy of your file as it is), release.json (the details; --meta release.json reads one back) and RELEASE.md. If the cover is not square, is under 3000 px, or is missing, the package is still written (your cover is never changed), but the console and RELEASE.md say so, and release.json lists it under cover_warnings.

3 · Read RELEASE.md

For every file: loudness, true peak, and the release checks. For the MP3 and AAC it also decodes the file again, the way a player does, and reports the true peak after decoding, because encoding can push a peak that was just under 0 dBTP over it. If a lossy file overshoots, it says by how much and that mastering again with the true-peak ceiling that many dB lower would fix it. It does not change the audio to hide the problem: that is a mastering decision, and yours (hypnomix master --ceiling).

Measured, not heard: play each file once before you upload. WAV files carry no tags; the details are in the file names and release.json.
