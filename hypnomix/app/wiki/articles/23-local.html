Maybe you'd rather not feed the data-center boom. Maybe you want your music and your tools to stay open source, end to end. Maybe a monthly AI subscription just isn't in the budget. All good: hypnomix doesn't need any of it. You can run an open-weight model on your own machine, driven by an open-source agent, and nothing ever leaves your computer.

Our recommendation: gpt-oss:20b, an open-weight model under the Apache 2.0 licence that's built for tool use (running commands, reading reports, trying again), served by Ollama (free) and driven by OpenCode (free, open source). It runs on a computer with 16 GB of memory or more, which covers most recent Macs with Apple silicon and many PCs. The download is about 14 GB.

Only 8 GB? Use a smaller model such as qwen3:8b in the same steps. It's lighter but less reliable on long jobs, so give it one command at a time.

  1. Install Ollama

    Ollama downloads and runs open models on your computer. Get the Mac app from ollama.com/download (or Ollama.dmg directly), drag it to Applications and open it. Or, in Terminal:

    $ curl -fsSL https://ollama.com/install.sh | sh

  2. Download the model

    $ ollama pull gpt-oss:20b          # about 14 GB, one time

  3. Give it room to think

    Agents need a long memory (the "context length"). Ollama defaults to a short one on most computers, and agents need at least 64,000. In the Ollama app, open Settings and drag the context-length slider to 64k. Or start Ollama from Terminal with it set:

    $ OLLAMA_CONTEXT_LENGTH=64000 ollama serve   # quit the Ollama app first if it's open

    A longer context uses more memory. If things crawl, check ollama ps: the PROCESSOR column should say 100% GPU.

  4. Install OpenCode, the agent

    OpenCode is a free, open-source agent that runs in Terminal. Install it with the one-line command on opencode.ai/docs.

  5. Start it on hypnomix

    $ cd hypnomix
$ source .venv/bin/activate
$ ollama launch opencode --model gpt-oss:20b

    Then just ask: "Run hypnomix doctor and tell me what's missing," or "Master Song mix.wav to -14 LUFS and check it on a phone." The agent reads AGENTS.md, runs the commands and reads the reports. (Already running OpenCode? Type /models and pick gpt-oss:20b; it finds Ollama by itself.)

Honest expectations. A local model is slower than a cloud one and makes more mistakes on long, multi-step jobs. hypnomix is built for that: every command writes a report, scan changes nothing, and fix only applies what you approve. A small model can take it one step at a time while REVIEW.md does the remembering. And you can always skip the AI and type the commands yourself; every one is on this page.
