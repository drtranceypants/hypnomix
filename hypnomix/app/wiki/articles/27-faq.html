Is hypnomix free?

Yes, free and open source under the MIT licence. It never needs a paid plug-in. The tip jar is optional.

Do I have to use a terminal or an AI?

No. hypnomix app opens a web app on your own computer that does the whole first pass by clicking (you can also build it into your own Mac app): choose a song, listen to each proposed fix, approve, apply. The Max for Live device lets you step through the findings inside Live. Installing hypnomix itself still takes a few terminal lines, once. More about the app.

Do I need Ableton Live?

Only for the Live features: controlling the open set, recording, and building device chains. The file tools (prep, automix, master, vocalign, tune, dehiss, translate, qc and more) work on audio files without Live.

Does it work on Windows?

It's built and tested on macOS. The file tools and Live control should work on Windows, but that's untested.

Will it mess up my Live set?

It saves a mixer snapshot before changing anything (hypnomix live restore undoes it), never deletes your plug-ins, and the scan → fix workflow writes approved changes into one new set while your original stays untouched. Every set it writes is checked for structural problems before you open it; one that fails is renamed so it can't be opened by accident. fix refuses to run if the set changed since the scan, never overwrites a file, and asks again before touching a track you marked as protected.

Will it quantise my playing or auto-tune my voice?

No. Timing tools move only the hits that are clearly out of time, and only part of the way; a full snap to the grid is refused. Tuning moves each note's centre toward the song's own tuning and keeps vibrato, scoops and slides. Every one of those changes is an item you approve, with a before-and-after clip.

How does it know what I like?

It asks once (hypnomix prefs), learns from your own finished songs (taste, voices --learn, motion --learn, profile) and remembers what you approve and skip in each review. All of it stays in a folder on your computer.

I use REAPER or Ardour

Point scan straight at the project: hypnomix scan "Song.rpp", or an Ardour session folder (Ardour 3 to 9). It reads the tracks, buses, takes or regions (as Ardour layers them), fades, plug-ins and automation, and runs the same checks as on a Live set. The DAW can stay open; nothing is written next to your project. For now, changes that belong in the project are listed for you to make there; repaired audio comes back as new files.

I use Logic, Pro Tools or something else

Export each track as a full-length file from the same start point and run hypnomix scan "that folder/". The review works the same way; repaired audio comes back as new files, and anything that has to happen in your DAW is listed as a to-do. Reading and writing other DAWs' projects is on the roadmap.

Can I use my own mastering chain?

Yes. In Live, put your chain (or rack) just before HypnomixMain on Main: Match target turns its Limiter until Main hits your loudness target, and Save keeps it as a template you can rebuild with one press. Live's own devices and racks keep every setting; plug-ins, Max for Live devices and macro mappings can't be rebuilt through Live's API, so they're listed as left out. Or press Build chain for hypnomix's neutral starting chain of stock devices and edit that. See Tell it in Live.

Is it AI?

The mixing and mastering decisions are measurement plus the rules an engineer would use; there are no black-box models in the mixing chain, so every move is written down with its reason. You can drive it with any AI agent if you like, including one running entirely on your Mac, and the optional Listener (or the critique command) lets a Google model hear a bounce and give a second opinion by ear, only when you click Send it.

Can I use it with AI but without paying for AI, or without a data center?

Yes. Run an open-weight model on your own computer with Ollama and drive it with the open-source OpenCode agent: free, offline, and nothing leaves your machine. We recommend gpt-oss:20b on computers with 16 GB of memory or more. Step-by-step setup here.

Will it replace a mixing engineer?

Treat it as a very fast assistant's first pass. Its checks measure; an optional Listener can add notes by ear, but it is a second opinion, not a decision. The taste calls are yours, or hire a human, or learn the craft in one-on-one lessons.

Where do the files go?

Into hypnomix-out/ in the folder you run it from (set HYPNOMIX_OUT to change it). Every tool writes a Markdown report next to its audio.

Something isn't working

Run hypnomix doctor first; it names what's missing. Then open an issue on GitHub.
