1. In the review, press Build A/B set for Live (or run hypnomix abset). It writes one new set where every proposed fix sits next to what you have, switched off: a copy of the changed device named "B · …", or a muted copy of the track with the clip fixes.
  2. Close your set, open the A/B set, and put the Hypnomix device on any track. It follows the review in the app, and Live jumps to each finding.
  3. Press A · now and B · fix while it loops. With the probe on Main and Match on, B is turned up or down to A's loudness, so you're judging the change and not just the level.
  4. Not sure? Press Blind: X and Y are A and B in a random order. Choose the one you like, and only then does it tell you which was which. The review shows how often you chose the fix.
The A/B set is for listening only. Approving still happens in the review, and Apply still writes the real new set from your original. Without Live, hypnomix ab plays before / after clips for clip fixes, tuning, timing nudges, frequency-fight cuts and changes to six of Live's devices. For a device it plays HypnoMix's model of it, not Live itself, and says so on the pair; for anything it cannot model (a Saturator or Reverb change, a plug-in, a return track), use this A/B set.
