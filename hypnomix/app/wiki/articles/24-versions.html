A release often wants more than the song: an instrumental, an a cappella, a TV mix, a shorter radio edit. If you export your stems, versions makes them from those files. There is no separation and no guessing: you say which stems are vocals, and the rest is addition. Your stems and mix are only read; everything lands in a new folder.

1 · Plan first: --check

$ hypnomix versions --stems "Song stems/" --vocals "Lead*,Harm*" --mix "Song master.wav" \
      --tv -6 --cut 1:12-1:40 --bpm 120 --check

Read-only: it sorts the stems into vocals and the rest, runs the null test, and prints each file it would write with its gain and the radio-edit cuts. Nothing is written.

2 · What you get

  • Instrumental: the stems that are not vocals, added up. A cappella: the vocal stems.
  • TV mix: the instrumental plus the vocals at --tv dB (--tv 0 is the full song). Only when you give --tv.
  • Radio edit: the song with each --cut range taken out, joined by short equal-power crossfades (--fade ms, default 30). It is cut from your --mix when you give one, so it keeps the master exactly; otherwise from all the stems. With --bpm each edge snaps to the nearest bar line, and the plan says where it landed. The bar grid is found from the audio to within about 30 ms, so an edge that lands within 50 ms of a drum hit (or another sudden hit) is moved onto the start of that hit; if there is no hit to land on, it stays on the grid. The plan says which edges were moved. Check the joins by ear.

--vocals takes names or patterns, comma separated, in any case, matched against the file name with and without its extension (Lead*, *Vox*, Harm 1). A reverb or delay exported as its own stem that you did not name stays in the instrumental, so name it if the a cappella should carry it.

3 · The null test

With --mix it first adds all the stems up and subtracts that from your mix. If the leftover is tiny, the stems really are the mix. If it is not, it says why in plain words: only level is different (a gain after the stems), the mix starts at a different point, or something real happens after the stems (master-bus compression, EQ, a limiter, a missing stem). In that case the versions are built from the stems, not carved out of the mix, and will not carry what your master bus does.

Each version is then gain-matched to the mix's loudness: gain only, no limiter, no EQ. If matching would push a true peak past the lower of the mix's own peak and -1 dBTP, the gain stops there and the report says how far short it landed. Without --mix no loudness is matched.

4 · The folder

$ hypnomix versions --stems "Song stems/" --vocals "Lead*,Harm*" --mix "Song master.wav" --tv -6 --cut 1:12-1:40 --bpm 120
# → hypnomix-out/versions/Song master (versions)/: instrumental, a cappella, TV mix, radio edit, VERSIONS.md, versions.json

qc runs on every file and VERSIONS.md has the results with the null test, the gains and the cut list. A cappellas and instrumentals often warn about a cut-off ending or silence at the start: that is what stems are like. Then release can package any of them.
