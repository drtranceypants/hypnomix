The web app. One command opens it in your browser; it runs on your computer only. Choose a Live set, or a folder of recordings from any DAW, and press one button: it runs every check and builds the before-and-after clips. The review shows each finding with play buttons for A and B and three choices: Approve, Skip, Change. Apply writes only what you approved into a new set next to your original, then shows exactly what changed. Your preferences and every other hypnomix tool are a click away, each with a form.

The Live device. A Max for Live device you drop on any track; audio passes through it untouched. It shows the finding you are on and steps through them, and Live jumps to each one: the track is selected, the playhead moves to the spot, the loop brace goes around it and the clip opens. Approve or skip right there. "Show in Live" buttons in the app do the same jump. The device never edits the set it sits in: applying still happens in the app, into a new set.

Both run on your computer only. Nothing is sent anywhere, and the app refuses requests from other sites. The device is new and needs Max for Live (Live Suite, or the add-on).

New: measure every track while Live plays, tell hypnomix what each track is and what the song is, A/B every fix inside Live with a blind test, and record a review before export. See the Training page for step-by-step lessons with pictures and videos.

$ hypnomix app          # opens http://127.0.0.1:8791 in your browser
$ hypnomix device       # optional: puts the Max for Live device in your Live User Library

Optional: make it a Mac app

Prefer an icon in your Dock to a browser tab? You can build your own Hypnomix.app: a small window around the same web app, which starts and stops it for you. It takes about a minute, and you build it yourself so it is made for (and trusted by) your own Mac.

1. Install Apple's command line tools once, if you haven't: xcode-select --install.
2. In the hypnomix folder, run macapp/build.sh.
3. Open macapp/dist/Hypnomix.app, or drag it into Applications.

If you move or reinstall the hypnomix folder, run the build again. The web app and the Mac app are the same thing inside; use whichever you like.

$ xcode-select --install     # once
$ cd hypnomix && macapp/build.sh
$ open macapp/dist/Hypnomix.app
