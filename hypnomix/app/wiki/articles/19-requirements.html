With the installer (download page) you need only a Mac running macOS 12 or newer, or a Windows 10/11 PC (64-bit), plus Live for the Live features: Python and ffmpeg come inside it. The table is for the source install. The app's Teacher tab, the free course in your own DAW, needs nothing more than the app, and no AI.

A Mac or a Windows PCEverything. Built and tested mostly on macOS; Windows is early and less tested; the unit tests run on both for every change. Linux: HypnoMix may run from source there, but the project does not test on Linux.
Python 3.9 or newerRuns HypnoMix. (Anthropic's library, for the Assistant's Claude provider, needs Python 3.10 or newer; on 3.9 the other providers work.)brew install python
ffmpegReading and writing audio formats, codec checks.brew install ffmpeg
uv (recommended)Fast, tidy installs into their own environment. Plain pip works too.brew install uv
gitDownloading and updating HypnoMix.brew install git
Ableton Live 11 or 12Only the Live features: controlling the open set, recording, building device chains. The file tools work without Live. A set saved by a newer major version of Live is read with one warning, and the tools that write a new set refuse it unless forced. Stock-device mastering uses Glue Compressor (Live Standard or Suite).ableton.com
REAPER (optional), HypnoMix DAW (add-on, not available yet)If you mix there instead: scan and project read REAPER projects (.rpp) and HypnoMix DAW sessions (.ardour) directly. HypnoMix DAW is an add-on that is not available yet, and its engine will be free software under the GNU General Public License: see HypnoMix DAW.HypnoMix DAW · reaper.fm
BlackHole 2chRecording what Live plays: loop, diagnose and chain --verify.brew install blackhole-2ch
Rubber Band (optional)Needed by tune and by vocalign's formant and transpose options; best-quality re-timing in vocalign, which falls back to its own method without it. Without it tune stops with one line that says how to get it on your system, and doctor lists it.brew install rubberband (Mac) · sudo apt install rubberband-cli (Linux) · Windows: the free command-line program from breakfastquay.com/rubberband, its folder on your PATH
An AI coding agent (optional)Asking for mixes in plain English. Any agent that can run terminal commands works. Open-source agents paired with a local model run entirely on your Mac: no account, no subscription, nothing leaves the computer.see With an AI agent · free & offline
