With the installer (download page) you need only a Mac running macOS 12 or newer, or a Windows 10/11 PC (64-bit), plus Live for the Live features: Python and ffmpeg come inside it. The table is for the source install. The app's Teacher tab, the free course in your own DAW, needs nothing more than the app, and no AI.

appneeded forget it
A Mac or a Windows PCEverything. Built and tested mostly on macOS; Windows is early and less tested.
Python 3.9 or newerRuns hypnomix.brew install python
ffmpegReading and writing audio formats, codec checks.brew install ffmpeg
uv (recommended)Fast, tidy installs into their own environment. Plain pip works too.brew install uv
gitDownloading and updating hypnomix.brew install git
Ableton Live 11 or 12Only the Live features: controlling the open set, recording, building device chains. The file tools work without Live. Stock-device mastering uses Glue Compressor (Live Standard or Suite).ableton.com
REAPER or Ardour (optional)If you mix there instead: scan and project read REAPER projects (.rpp) and Ardour sessions (Ardour 3 to 9) directly. Ardour is free and open source.ardour.org · reaper.fm
BlackHole 2chRecording what Live plays: loop, diagnose and chain --verify.brew install blackhole-2ch
Rubber Band (optional)Best-quality re-timing in vocalign; it falls back to its own method without it.brew install rubberband
An AI coding agent (optional)Asking for mixes in plain English. Any agent that can run terminal commands works. Open-source agents paired with a local model run entirely on your Mac: no account, no subscription, nothing leaves the computer.see With an AI agent · free & offline

The Python libraries (numpy, scipy, librosa, soundfile, pyloudnorm, noisereduce, python-osc and friends) install automatically in step 3 below. The bundled AbletonOSC remote script is installed for you in step 4.
