hypnomix is a set of terminal commands that write plain-text reports, so any AI coding agent that can run commands in a folder can drive it. Open the hypnomix folder in your agent and ask for what you want:

"Mix the stems in ~/Music/Bounces/Night Drive. Make it sound like this reference."
"I'm about to record acoustic guitar on input 2. Set up a track and check my levels."
"Do a first pass on ~/Music/Song Project/Song.als. The mix is Song.wav."
"Master this for Spotify and check it'll survive on a phone."

Rather not use a cloud AI at all? You don't have to. See Run your own AI, free and offline below.

What the agent gets. AGENTS.md in the repo is written for any agent: setup, the loop every job follows, the safety rules (ask your preferences first, scan before changing anything, one item at a time with you, new files only, measure again afterwards), the command map and how to extend the code. The skills/ folder holds six ready-made workflows (first-pass, harmony-balance, mix-engineer, mastering-engineer, tracking-session, live-mixing), and docs/LESSONS.md lists the real mistakes the rules come from, so your agent doesn't repeat them. Agents with skill support load them directly; any other agent can read them as plain instructions.

Building inside Live. The included MCP config connects the open-source Ableton MCP (telemetry off), so agents that speak MCP can create tracks and load devices, and rebuild an automix inside your set from recipe.json.
