Four tools work together here. Two run live in Ableton (the Turnaround device), two prepare material for it (loopedges and loopset), and one lets you hear the fills offline first (turnaround). They are for Ableton Live only for now.

The Turnaround device (Fills)

hypnomix turnarounddevice makes a Max for Live audio effect and puts it in your Live User Library (or --out a folder). Drop it on a track playing a loop. Every few bars it changes the end of the loop: repeats, stutters, reverses, crushes, echoes, gaps, so the loop doesn't sound the same each time round.

ControlWhat it does
CycleA fill every 4, 8 or 16 bars
WhereHow long the fill is: the last 4, 8, 16 or 32 steps of the cycle
Level1 subtle, 2 busier, 3 wild
ChanceHow likely each fill is to play at all
EvolveA new pattern every N fills (0 keeps one pattern)
Effect weightsHow often each effect is picked; 0 turns it off
Keep lowsKeeps the bass and kick steady under the fill
MixFill against the dry loop

Every cut gets a short fade, so fills never click, and the timing follows Live's transport.

Hear it offline: turnaround

hypnomix turnaround LOOP.wav --bpm 124 renders the same fills onto a loop file without opening Live, with the same controls as flags (--cycle, --where, --level, --chance, --evolve, --weights repeat=3,echo=0, --seed, --mix). The same seed gives the same fills as the device. --json writes the pattern it chose.

Clean loop edges: loopedges

hypnomix loopedges FILE --bpm 124 --bar 9 --bars 4 cuts a loop so its first downbeat sits exactly at the clip start and nothing of the next bar's first hit leaks onto the end. It works on audio (WAV, FLAC, AIFF) and on MIDI files. Use --downbeat for where bar 1 starts in seconds, --bpb for beats per bar and --fade-ms for the edge fades.

Loop sets: loopset

loopset finds the parts of a song that loop best and builds a set of them for you to play with. It has two modes.

From stems. Export every track from your song (all starting at bar 1) and run hypnomix loopset STEMS_FOLDER. It finds the tempo and the first bar from the drums, scores every 1, 2, 4 and 8 bar window on how well its end leads back to its start and how steady the section is, keeps the best --top (6) from different sections, cuts every stem on the same clean edges and makes --variations (4) of the drum loop. --complexity subtle|normal|complex sets how far the variations go.

From long takes. hypnomix loopset --takes SET.als reads a Live set with long recorded takes (a B-take of a guitar part, say). For each track (--tracks "Guitar,Keys" to choose) it finds the best --per-track (6) loops, makes variations, and adds --combos (16) scenes that play loops from different tracks together.

Add --set SET.als --apply NEW.als (stems mode) or --apply NEW.als (takes mode) to get a new Live set. It adds a "<track> loops" track for each source, fills scenes named "Combo n", "Pick n" and "Pick n v2", warps every clip at the set's tempo, and uses the set's empty scenes before adding new ones. It never overwrites a file: give it a new name. Close the original set in Live before you open the new one.

The Turnaround device sits well on the new loop tracks: fire a scene, and the fills keep it moving.
