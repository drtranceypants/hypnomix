The quickest way is the installer for Mac or Windows (Install). These are the steps for the terminal, which is also how you work on hypnomix itself.

$ brew install python ffmpeg uv git rubberband
$ git clone https://github.com/drtranceypants/hypnomix && cd hypnomix
$ uv venv && uv pip install -e . && source .venv/bin/activate
$ uv pip install -e ".[plugins]"     # optional: render through your own plug-ins (lesson 11)
$ hypnomix doctor                     # checks every part and says what is missing
  1. For the Live features, run hypnomix install once and restart Live, then pick AbletonOSC as a Control Surface in Live's settings (Link, Tempo & MIDI).
  2. For the Max for Live devices (Live Suite, or Live with the Max for Live add-on): hypnomix device and hypnomix probe device put them in your User Library. They appear in Live's browser under User Library → Presets → Audio Effects → Max Audio Effect → Hypnomix.
  3. Start the app with hypnomix app. It opens in your browser and runs only on your computer.
