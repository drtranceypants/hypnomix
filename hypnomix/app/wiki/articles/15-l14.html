$ hypnomix scan "Song.als" --quick                 # structure, edges, levels: seconds, no rendering
$ hypnomix scan "Song.als" --since "hypnomix-out/scan/Song"   # only the tracks you changed
$ hypnomix watch "Song.als"                        # every time you save in Live, a quick check of what changed

Rendered clips are cached by their source file and settings, so a second scan of the same song re-renders nothing it has already rendered. The library scan, the names, the pitch analysis and the sound classifier are cached the same way.

A re-scan into the same folder keeps each decision you made on the finding it was made for, matched by what the finding is (tool, track, kind and place), never by its number. A decision whose finding is gone is counted, set aside in a file and never applied.
