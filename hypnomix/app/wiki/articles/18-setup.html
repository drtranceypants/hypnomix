HypnoMix works the same way everywhere: it scans, you approve, it writes only what you approved into a new project or new files. What changes is which DAW you use and how you drive it. Pick one of each.

One app, one installer

The download page has one installer for each computer (Mac with Apple silicon, Mac with an Intel chip, Windows), the same for everyone. It is the app and every HypnoMix tool, for Live, REAPER, HypnoMix DAW or any DAW from exported tracks. Nobody has to fetch a second program to use their own DAW.

HypnoMix DAW is HypnoMix's own DAW (what it is built on). It is an add-on, not a second download, and it is not available yet: no archive of it is published, so there is nothing to add and the app downloads nothing. When it is published (for the Mac first, not yet for Windows), choosing HypnoMix DAW in the app's guided setup shows what it is and a button, Add HypnoMix DAW. Only that click fetches it: expected to be about 100 MB, once, from the project's release page, checked against a SHA-256 fingerprint before it is used; it runs only while the DAW view is open, and Setup → Extras removes it again. Until then your choice is remembered and nothing changes.

Its engine is a separate program under the GNU General Public License (version 2 or later), downloaded on its own; HypnoMix itself stays MIT and contains none of its code. The source will be published with the first release that includes the engine. Not yet checked: playing through a real sound card (only the silent test backend has been run), recording, the app's native File menu, the add-on's own download and unpacking on a real release, signing and notarising it, and Intel Macs.

The app's Wiki then shows your DAW's pages first.

What has been checked where. The Live devices and the Live fix paths were tested in Live 12, and REAPER support in REAPER 7.86. The newest additions (the new commands, EQ bands written for masking cuts, ab previews of timing nudges and device changes, and fix on a HypnoMix DAW session) pass unit tests and HypnoMix's own structure checks on synthetic data. The REAPER files they write (the demo project, a project written by fix, ReaEQ masking bands, the hand-off marker and the A/B project) were opened in REAPER 7.86 and read back as written. On 2026-11-26 the newest REAPER parts were also tried in REAPER 7.86 on a two-track test project, never a real song and not judged by ear: the HypnoMix Probe, HypnoMix Main, Review and Align windows opened and their guides were captured by screenshot (not clicked through by hand); reaper snapshot, diff and restore were exact; reaper loop --ab measured its change and --revert put the mix back; reaper diagnose put every solo back (no project with folders was tried); a ReaComp written by fix and the vocallevel --apply envelopes read back as written. Not checked: clicking the windows by hand, Windows, ReaGate and ReaLimit settings, and diagnose with folders. The new Live sets and the HypnoMix DAW snapshots have not been opened in their DAWs yet, the new tools have not been run on real songs, and nothing new has been judged by ear. HypnoMix DAW's newest parts (take lanes, groups, the meter stream, cue slots, the A/B session) were tried only against stand-in engines and a development engine with no sound, never on Windows or by ear (DAW mode lists what was not tried).
