What it does. hypnomix plugins looks in the standard plug-in folders of your computer and lists what is there, by format: VST3, Audio Units (on a Mac), CLAP and LV2. The ones that are on the free list in the README are marked, so a proposal can use them. Every other plug-in is listed but never proposed. Nothing is changed: the only file it ever writes is your preferences, and only when you ask.

Try it.

hypnomix plugins                       # what is installed
hypnomix plugins --free                # only the free list
hypnomix plugins --check               # also load each one, without its window
hypnomix plugins --save                # keep the list in your preferences
hypnomix plugins --json                # the same as data, for an agent

Checking that each one loads. --check opens every VST3 and Audio Unit once, without showing its window, to see that it starts. Each plug-in is opened in its own process with a time limit (--timeout, 60 seconds by default), so one that crashes or hangs is listed as FAILED with the reason, and the run goes on to the next. It needs the optional plugins extra (the same one plugrender uses). CLAP and LV2 plug-ins are listed as found but marked "not checked", because the host can only open VST3 and Audio Units.

Keeping the list. --save writes two things into your preferences: tools.plugins, the free-list plug-ins you have (and, with --check, that load), and tools.plugins_found, everything found. Plug-ins you added by hand to tools.plugins stay unless you give --replace. --save always keeps the whole list, so it is refused together with --only or --free, which only narrow what is shown. --json FILE writes a new file in a folder that exists and never replaces one that is already there. hypnomix prefs shows the list. colour reads it, so it only names plug-ins you have.

If yours live somewhere else. Add the folder with --folder FORMAT=DIR (for example --folder vst3=D:\Plugins), as often as you like, or use --no-system to look only there.

Limits. It reads folders, not a host's own scan: a plug-in in a folder hypnomix doesn't know isn't listed until you add the folder. Audio Units are read from their Info.plist, the others by file name. It does not say whether a plug-in is licensed or in a demo period; "loads" means it started.
