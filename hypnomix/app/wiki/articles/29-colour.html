The idea. A part that plays the same way in every repeat can make a song feel frozen. A different colour on the second chorus (a little more width, some grit, another room, a slow filter drift) changes how it feels without changing a note. hypnomix colour finds where that would help and proposes a chain to try there. It adds nothing to your song unless you pick a proposal by number.

Try it. Close the set in Live first if you plan to write one.

hypnomix colour "Song.als"                                  # the report and the before / after clips
hypnomix colour "Song.als" --part Pad --family grit          # choose the part and the kind of colour
hypnomix colour "Song.als" --apply "Song (colour).als" --ids colour-1,colour-3

How it decides where. The song is cut into sections on its own bar lines (the method sections uses; --block 8 cuts every eight bars instead). Each part is measured in each section it plays: its tone (how its energy is spread over six bands, in dB), how bright it is, and its texture (notes per bar). A part "sounds the same" where its tone and texture are within --static (2 dB by default) of what it already did in an earlier section; the report shows, for every part, how much it changes from section to section. A proposal goes where the part repeats itself and the whole mix repeats with it. The first time through is never proposed. This is measured, not heard: your ears overrule the number.

The kinds of colour. width (chorus and a Utility width; never for bass), grit (Saturator), space (a reverb: a room for busy parts, a hall for sustained ones), movement (a slow Auto Filter drift) and octave (a quiet Shifter copy an octave up, or --octave down). Without --family it picks the kind that suits what it measured, and says why. --max sets how many proposals, --per-part how many on one part, --amount 0 to 1 how strong (and per proposal in a review note: amount=0.3).

What a proposal is. A chain of Live's own devices, started from a preset in Live's library and set by name, on a copy of the part: a new track right after it, in the same group, with the same devices and sends, switched off, holding only the clips for those bars. Turn it on, and turn the original off for those bars if you want to hear it instead. Each proposal comes with four bars of the part as it is and the same bars through a model of the chain, level matched. The model is an approximation written for HypnoMix, so it shows the direction; only Live plays the real devices.

In the review. --plan writes the proposals as findings into a scan folder, with their clips, so you go through them with hypnomix review like any other fix and hypnomix fix DIR --approved writes only the ones you approved, into one new set.

Your free plug-ins. If you saved your list with hypnomix plugins --save, a proposal names the installed free plug-ins that suit its kind of colour, as alternatives to try by hand. HypnoMix does not write a third-party plug-in into a set (it never touches their saved settings), so the chain it writes is always Live's.

Not there yet. It writes Live sets only: REAPER and HypnoMix Studio projects are not written yet. A new instrument doubling a line (from midi) is not built. The written set passes hypnomix check and has not yet been opened in Live, and the chains' values are those of Live's own presets with a few set by name, so listen before you trust them. Needs a constant tempo; it finds Live's library by itself, or give --library.
