1. Install Homebrew (skip if you have it)

    Homebrew installs the free tools hypnomix needs. Open Terminal (Applications → Utilities) and paste the line from brew.sh, then follow its prompts.

  2. Install the tools

    $ brew install python ffmpeg uv git
$ brew install blackhole-2ch rubberband   # recommended: recording from Live, best vocal re-timing

  3. Download and install hypnomix

    $ git clone https://github.com/drtranceypants/hypnomix && cd hypnomix
$ uv venv && uv pip install -e .
$ source .venv/bin/activate          # do this in each new Terminal window
$ hypnomix                            # prints the command list

    No uv? python3 -m venv .venv && source .venv/bin/activate && pip install -e . does the same.

  4. Connect it to Ableton Live

    $ hypnomix install

    This copies the bundled AbletonOSC remote script into Live's User Library and walks you through the rest, including the two-minute BlackHole setup. Then restart Live and choose Settings → Link, Tempo & MIDI → Control Surface: AbletonOSC.

    To reach more of your plug-ins' parameters: hypnomix install --plugin-params (adds one line to Live's Options.txt; restart Live).

  5. Check everything

    $ hypnomix doctor

    It checks Live, AbletonOSC, BlackHole, ffmpeg and plug-in parameter access, and tells you what to fix.

  7. Updating later

    $ cd hypnomix && git pull && uv pip install -e .
