One download. The download page has one installer for each computer, the same for everyone: the app and every HypnoMix tool, for Live, REAPER, HypnoMix DAW or any DAW. HypnoMix DAW, HypnoMix's own DAW (what it is built on), is an add-on you add from the app's Setup only if you want it, so nobody who keeps their own DAW downloads an engine they do not use. It is not available yet: no archive of it is published, so there is nothing to add and the app downloads nothing. When it is, it will be for the Mac first (expected to be about 100 MB, fetched once from the project's release page, checked against a SHA-256 fingerprint before it is used, run only while the DAW view is open, removable from Setup → Extras). Its engine is a separate program under the GNU General Public License (version 2 or later), with its own licence text and source notice; HypnoMix itself stays MIT and contains none of its code. The source will be published with the first release that includes the engine. The engine has not been checked with a real sound card (only the silent test backend was run), for recording, through the native File menu, as a downloaded add-on from a real release, signed, or on Intel Macs.

The easy way: the installer. Download HypnoMix from the download page (Mac with Apple silicon, Mac with Intel, or Windows 10/11). It carries its own Python and ffmpeg, so there is nothing else to install. On a Mac, drag HypnoMix to Applications; on Windows, run the setup. The first time, your computer warns that the app isn't signed yet: the download page shows how to open it anyway, and links to the public virus-scan reports.

When it opens, a guided setup asks how you want to work (on your own, with an AI key such as Gemini's free tier, with a free model on your own computer, or with Claude Code), which DAW you use (Live, REAPER, HypnoMix DAW or something else; and offers teacher mode), connects it, connects your DAW, and offers the optional extras. Setting Up, and Choosing an AI walks through each option with costs.

Optional extras in the app. Setup's Extras step installs reference matching, your own VST3 / AU plug-ins, and stem separation with audio to MIDI, each on a click. They download from PyPI into ~/.hypnomix/extras, outside the app, so an update to the app keeps them. Delete that folder to remove them. Libraries the app already has are kept at the app's own versions.

Claude Code skills in the app. Choosing A desktop AI app makes an AI agent folder with the repository's skills (first-pass, mix-engineer, mastering-engineer and the rest) and its scanner subagent in .claude/. Claude Code finds them when it opens that folder.

From the source, below, is for the terminal and for working on HypnoMix itself. Linux: HypnoMix may run from source there, but the project does not test on Linux.

From the source (Mac)

  1. Install Homebrew (skip if you have it)

    Homebrew installs the free tools HypnoMix needs. Open Terminal (Applications → Utilities) and paste the line from brew.sh, then follow its prompts.

  2. Install the tools

    $ brew install python ffmpeg uv git
$ brew install blackhole-2ch rubberband   # recommended: recording from Live, best vocal re-timing

  3. Download and install HypnoMix

    $ git clone https://github.com/drtranceypants/hypnomix && cd hypnomix
$ uv venv && uv pip install -e .
$ source .venv/bin/activate          # do this in each new Terminal window
$ hypnomix                            # prints the command list

    No uv? python3 -m venv .venv && source .venv/bin/activate && pip install -e . does the same.

  4. Connect it to Ableton Live

    $ hypnomix install

    This copies the bundled AbletonOSC remote script into Live's User Library and walks you through the rest, including the two-minute BlackHole setup. Then restart Live and choose Settings → Link, Tempo & MIDI → Control Surface: AbletonOSC.

    To reach more of your plug-ins' parameters: hypnomix install --plugin-params (adds one line to Live's Options.txt; restart Live).

  5. Check everything

    $ hypnomix doctor

    It checks ffmpeg and the Python packages, and, if you use Ableton Live, AbletonOSC, the Live connection, BlackHole and plug-in parameter access, and tells you what to fix. On a computer without Live those Live parts are marked optional (·) and never make it report a problem.

  6. Optional extras

    Run each install line in the HypnoMix folder. (HypnoMix is not on PyPI, so pip install hypnomix does not work.)

    extraaddsinstall
    referencehypnomix reference (Matchering; GPL-3.0, kept separate so HypnoMix stays MIT)uv pip install -e ".[reference]"
    mlseparate (split a song into stems) and midi (audio → MIDI)uv pip install -e ".[ml]"
    pluginsplugrender and ab --plugins: render through your real VST3 / AU plug-ins (pedalboard; GPL-3.0, kept separate)uv pip install -e ".[plugins]"
    assistantthe app's Assistant tab: your own key from Anthropic, OpenAI or any OpenAI-compatible service, or a model on your own computer (the installers already include it)uv pip install -e ".[assistant]"
    critiquea cloud model listens and writes notes by ear (your own Google Gemini or OpenRouter key; also the Assistant's Listening; the installers already include it)uv pip install -e ".[critique]"

  7. Updating later

    $ cd hypnomix && git pull && uv pip install -e .
