I'm new to all this: where do I start?

With the free Teacher tab in the app (hypnomix app, or the installed app). Turn on teacher mode in the guided setup, choose your DAW (Live, REAPER or HypnoMix DAW) and pick a course: the complete course from what sound is to releasing a song, a 101 crash course, or a tour of HypnoMix. It needs no AI and nothing extra to install. When you have a song, hypnomix demo writes a short practice song with six labelled problems, so you can run the first pass on it before you trust it with your own music. Choose your setup.

Is HypnoMix free?

Yes, free and open source under the MIT licence. It never needs a paid plug-in. The tip jar is optional.

Does HypnoMix send crash reports or usage data?

No. HypnoMix has no server of its own and never phones home: no usage data, no analytics, no automatic crash reports. The app does ask the internet for two things, and only those: GitHub's list of releases (to tell you when a new version is out) and the website's list of Wiki articles (to keep the Wiki current); neither request carries a report, a song or your setup. When it hits a bug it saves a crash record on your computer (the newest 20 are kept in ~/.hypnomix/crashes) and tells you in one sentence. If you want to report a problem, hypnomix report (or Report a problem in the app) writes a report you can read first, with your paths, names and keys hidden, and you copy it, save it or paste it into the project's public issue page yourself. See Reporting a problem.

Do I have to use a terminal or an AI?

No. hypnomix app opens a web app on your own computer that does the whole first pass by clicking (you can also build it into your own Mac app): choose a song, listen to each proposed fix, approve, apply. The Max for Live device lets you step through the findings inside Live. Installing it doesn't need a terminal either: download the installer for Mac or Windows from the download page, and its guided setup asks whether you want an AI at all. More about the app.

Do I need Ableton Live?

Only for the Live features: controlling the open set, recording, and building device chains. The file tools (prep, automix, master, vocalign, tune, dehiss, translate, qc and more) work on audio files without Live.

A command says "can't read ... as audio"

The file is missing, is a folder, or is not audio HypnoMix can decode (a damaged export, or a project file given where a bounce was expected). The message names the file and says which; the command stops with exit code 2. measure carries on with the other files of a batch and still exits non-zero if any failed. To see the technical detail instead, set HYPNOMIX_DEBUG=1 and run it again.

Does it work on Windows?

Yes, early: there's a Windows installer on the download page, and the app runs in your browser there. HypnoMix is built and tested mostly on macOS, so Windows has had less real use; please report anything that breaks.

Does it work on Linux?

Linux: HypnoMix may run from source there, but the project does not test on Linux. There is no Linux installer. The code keeps the Linux paths it has (for example where it looks for plug-ins and how it opens a file), and patches from people who use Linux are welcome.

How much of this has been tested?

The Live devices and the Live fix paths were tested in Live 12, and REAPER support in REAPER 7.86. The newest additions pass unit tests and HypnoMix's own structure checks on synthetic data. The REAPER files they write (the demo project, a project written by fix, ReaEQ masking bands, the hand-off marker and the A/B project) were opened in REAPER 7.86 and read back as written. The new Live sets have not been opened in Live, and the HypnoMix DAW snapshots have not been opened in a released DAW, yet, the new tools have not been run on real songs, and nothing new has been judged by ear. Anything marked new: keep your original and listen. Opening it all for real is the first job on the roadmap.

Will it mess up my Live set?

It saves a mixer snapshot before changing anything (hypnomix live restore undoes it), never deletes your plug-ins, and the scan → fix workflow writes approved changes into one new set while your original stays untouched. Every set it writes is checked for structural problems before you open it; one that fails is renamed so it can't be opened by accident. fix refuses to run if the set changed since the scan, never overwrites a file, and asks again before touching a track you marked as protected.

Will it quantise my playing or pitch-correct my voice?

No. Timing tools move only the hits that are clearly out of time, and only part of the way; a full snap to the grid is refused. Tuning moves each note's centre toward the song's own tuning and keeps vibrato, scoops and slides. Every one of those changes is an item you approve, with a before-and-after clip.

How does it know what I like?

It asks once (hypnomix prefs), learns from your own finished songs (taste, voices --learn, motion --learn, profile) and remembers what you approve and skip in each review. All of it stays in a folder on your computer.

I use REAPER or HypnoMix DAW

Point scan straight at the project: hypnomix scan "Song.rpp", or a HypnoMix DAW session folder (a folder with a .ardour file in it; what HypnoMix DAW is). It reads the tracks, buses, takes or regions (as the session layers them), fades, plug-ins and automation, and runs the same checks as on a Live set. In REAPER, fix then writes what you approve into a new project (yours stays untouched), and REAPER has its own versions of the Live devices: Hypnomix Probe and Main (meters, the song card, Record and review, a mastering chain), the A/B review panel and the HypnoMix Align panel. For a HypnoMix DAW session, fix writes approved fades, gain, dips, and fader, pan and mute moves into a new .ardour snapshot (written and re-read by HypnoMix; not yet opened in a released DAW); everything else that belongs in the session is listed for you to do there, and repaired audio comes back as new files.

What is HypnoMix DAW, and what is it built on?

HypnoMix DAW is HypnoMix's own DAW. It is an optional add-on: there is one app, HypnoMix, and you choose HypnoMix DAW as your DAW in Setup (or add it later under Extras). The article HypnoMix DAW says what it is built on and gives the credit, and the add-on carries its licence and a source notice. HypnoMix itself stays MIT. HypnoMix DAW is not released yet: Setup says so, nothing is downloaded, and the article says what to use until it is. What the app does with it is in DAW mode.

I use another DAW

Export each track as a full-length file from the same start point and run hypnomix scan "that folder/". The review works the same way; repaired audio comes back as new files, and anything that has to happen in your DAW is listed as a to-do: hypnomix handoff turns that list into a checklist in your DAW's words, with a MIDI marker file and a CSV you can import. HypnoMix has no reader for other DAWs' sessions yet; they are on the roadmap for later.

Can I use my own mastering chain?

Yes. In Live, put your chain (or rack) just before HypnomixMain on Main: Match target turns its Limiter until Main hits your loudness target, and Save keeps it as a template you can rebuild with one press. Live's own devices and racks keep every setting; plug-ins, Max for Live devices and macro mappings can't be rebuilt through Live's API, so they're listed as left out. Or press Build chain for HypnoMix's neutral starting chain of stock devices and edit that. In REAPER, HypnoMix Main has the same three buttons, and Save chain keeps everything before it as an FX chain file, plug-ins of any make included. See Tell it in Live.

Is it AI?

The mixing and mastering decisions are measurement plus the rules an engineer would use; there are no black-box models in the mixing chain, so every move is written down with its reason. You can drive it with any AI agent if you like, including one running entirely on your Mac, and the optional Listener (or the critique command) lets a Google model hear a bounce and give a second opinion by ear, only when you say yes: the app shows the length, model and estimated cost with Send it and Don't, and critique asks y/N in a terminal and refuses elsewhere unless you pass --yes.

Can I use it with AI but without paying for AI, or without a data center?

Yes. Run an open-weight model on your own computer with Ollama and drive it with the open-source OpenCode agent: free, offline, and nothing leaves your machine. We recommend gpt-oss:20b on computers with 16 GB of memory or more. Step-by-step setup here.

Will it replace a mixing engineer?

Treat it as a very fast assistant's first pass. Its checks measure; an optional Listener can add notes by ear, but it is a second opinion, not a decision. The taste calls are yours, or hire a human, or learn the craft in one-on-one lessons.

Where do the files go?

Into hypnomix-out/ in the folder you run it from (set HYPNOMIX_OUT to change it). Every tool writes a Markdown report next to its audio.

Something isn't working

Run hypnomix doctor first; it names what's missing. Then open an issue on GitHub.
